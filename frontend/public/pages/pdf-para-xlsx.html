PDF para Excel

Envie um arquivo .pdf e receba uma planilha .xlsx com as tabelas do documento, uma por aba.

O que é convertido

  • Cada tabela do PDF vira uma aba da planilha, na ordem das páginas
  • Números viram números de verdade no Excel, prontos para somar e ordenar
  • Sem tabelas no PDF, cada página vira uma aba com o texto, linha a linha

Limitações

  • PDFs escaneados (imagem) não têm texto para extrair: não há OCR.
  • Tabelas sem linhas de grade ou com células mescladas podem sair incompletas ou não ser detectadas.
  • Formatação (cores, fontes, bordas) não é copiada, e PDFs protegidos por senha não são aceitos.
