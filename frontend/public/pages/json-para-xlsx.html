JSON para Excel

Envie um arquivo .json com uma lista de objetos e receba uma planilha .xlsx.

Formato esperado

Uma lista de objetos com as mesmas chaves. Cada chave vira uma coluna e cada objeto vira uma linha. 

[
  { "nome": "Ana",   "idade": 30 },
  { "nome": "Bruno", "idade": 25 }
]
Planilha gerada a partir do exemplo
nomeidade
Ana30
Bruno25
